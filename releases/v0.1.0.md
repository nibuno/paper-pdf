# Paper PDF Prototype v0.1.0

技術書PDFを読み、線や付箋、ページメモを残すmacOSアプリの初版です。元のPDFファイルは変更せず、書き込みと読書位置をMac内に自動保存します。

## できること

- 連続スクロール・1ページ・見開きでの読書と、前回の続きからの再開
- 鉛筆・ペン・蛍光ペン・消しゴム、取り消しとやり直し
- 付箋の一覧とページ移動、ページメモ、選択テキストの引用
- 読み返した回数に応じて少しずつ変わる紙色や質感

## 対応環境とインストール

Apple Silicon搭載Mac（M1以降）、macOS 14以降が対象です。Intel Mac向けの配布物は含みません。

macOS 14での実機動作と、別のMacへダウンロードした際の初回起動は未確認です。

1. Assetsから `PaperPDFPrototype-0.1.0-macos-arm64.zip` をダウンロードして展開します。GitHubが用意する「Source code」は開発用のソースです。
2. `PaperPDFPrototype.app` を「アプリケーション」フォルダに移動して開きます。
3. この版は簡易署名のみで、Developer ID署名・Appleの公証はありません。初回に警告が出た場合、配布元を確認したうえで「システム設定 → プライバシーとセキュリティ → このまま開く」から、このアプリを許可してください。

詳細は[Appleの起動手順](https://support.apple.com/ja-jp/102445)を参照してください。管理されたMacでは起動許可が制限される場合があります。

ダウンロードの整合性は、ZIPと `.sha256` を同じフォルダに置き、そのフォルダで次のコマンドを実行して確認できます。

```bash
shasum -a 256 -c PaperPDFPrototype-0.1.0-macos-arm64.zip.sha256
```

## この版の制限

- 画像PDFのOCR、パスワード入力によるロック解除は未対応です。
- PDF側でコピー・注釈が禁止されている場合、該当する操作は利用できません。
- メモと書き込みはこのアプリ専用です。PDFへの書き出しや別のMacとの同期はありません。
- アプリ内の自動更新はありません。次の版はReleasesからダウンロードしてください。

メモと書き込みは `~/Library/Application Support/PaperPDFPrototype/Sidecars/` に保存されます。アプリを入れ替えても残ります。バックアップには、このフォルダと元のPDFの両方を含めてください。
